# BytexGrid Portfolio Project

## Project Overview
A cutting-edge portfolio website showcasing BytexGrid's open-source projects and development journey.

## Tech Stack
- **Frontend:**
  - Next.js 14 (React framework)
  - TailwindCSS
  - Framer Motion (for animations)
  - TypeScript

- **Backend/API:**
  - Next.js API routes
  - GitHub API integration

- **Deployment:**
  - Vercel
